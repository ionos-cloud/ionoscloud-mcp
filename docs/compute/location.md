# Locations

## list_locations

Lists all available locations (regions) in IONOS CLOUD.

**Parameters:** None

**Example:**

```json
{
  "name": "list_locations",
  "arguments": {}
}
```

**API Reference:** [locationsGet](https://api.ionos.com/docs/cloud/v6/#tag/Locations/operation/locationsGet)
