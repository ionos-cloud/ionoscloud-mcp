# Images

## list_images

Lists all available images (OS templates) in IONOS Cloud.

**Parameters:** None

**Example:**

```json
{
  "name": "list_images",
  "arguments": {}
}
```

**API Reference:** [imagesGet](https://api.ionos.com/docs/cloud/v6/#tag/Images/operation/imagesGet)
