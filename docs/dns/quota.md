# DNS Quota

## get_dns_quota

Gets DNS quota usage and limits for your IONOS Cloud account.

**Parameters:** None

**Example:**

```json
{
  "name": "get_dns_quota",
  "arguments": {}
}
```

**API Reference:** [quotaGet](https://api.ionos.com/docs/dns/v1/#tag/Quota/operation/quotaGet)
