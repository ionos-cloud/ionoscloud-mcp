# Support

## Questions, bug reports, and feature requests

Open a [GitHub Issue](https://github.com/ionos-cloud/ionoscloud-mcp/issues/new/choose)
and pick the matching template (bug report, feature request, or question).

For bug reports, please include:
- `ionoscloud-mcp` version (output of `ionoscloud-mcp --version` or the Docker
  image tag)
- MCP client and its version (Claude Desktop, Claude Code, Cursor, etc.)
- Steps to reproduce
- Expected vs actual behaviour
- Relevant logs from **stderr** (the server uses stdout exclusively for the
  JSON-RPC channel)

## IONOS CLOUD account issues

Issues with the IONOS CLOUD platform itself — billing, account access, API
errors that look like outages — should be raised with IONOS CLOUD support, not
in this repository.

## Security issues

See [SECURITY.md](SECURITY.md). Do not report vulnerabilities in public Issues
or Discussions.
